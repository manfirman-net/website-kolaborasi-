Matematika

Model Variabel:

x = Harga 1 Pot Keyboard

y = Harga 1 Kipas Angin Smart

Paket 1: 5x + 3y = 350.000

Paket 2: 3x + 5y = 450.000

Metode Campuran

Eliminasi:

5x + 3y = 350.000 |*5

3x + 5y = 450.000 |*3

25x + 15y = 1.750.000

9x + 15y = 1.350.000

___________________ -

16x = 400.000

x = 400.000 / 16

x = 25.000

Substitusi:

5x + 3y = 350.000

5(25.000) + 3y = 350.000

125.000 + 3y = 350.000

3y = 350.000 - 125.000

3y = 225.000

y = 225.000 / 3

y = 75.000

Kesimpulan: Jadi, harga 1 Pot Keyboard adalah Rp25.000 dan harga 1 Kipas Angin Smart adalah Rp75.000
